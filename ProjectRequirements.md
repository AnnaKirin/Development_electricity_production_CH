TSM InfVis Module Task
ImportantThe TSM InfVis Module Task is Graded
The grade of the module task counts for 25% of the final grade, 75% of the grade are the module exam. The module task requires two submissions (see below), both submissions are graded. The completion of the Moodle questionnaire can achieve a maximum of 5 points, the submission of the completed module task pdf can achieve a maximum of 35 points.

The module task comprises the completion of a visualization project on a selected topic. It runs in parallel to the teaching and the exercises throughout the semester. You can complete the module task either on your own or in a team of maximal two students. Select a topic and find relevant data. If possible, select data and topic in an area that you are interested in and where there is data available to you. You are free to use any data, software, and tools available to you. Please make sure that the data is not confidential and that you are allowed to complete, submit, and discuss (in class) the project based on it.

Topic/Data Requirements
use data from a topic that interests you but make sure your data has at least four [4] different substantial data dimensions, including space OR time (or both), this may be achieved by adding context information to a data set
Make sure you are allowed to use the data, to complete the module task with the chosen data, and to show the results in class. Do NOT use confidential data (at least your teacher, and ideally also your fellow students, should be allowed to view your submission) and make sure that the data is available to you NOW. Do not start an information visualization project where the data may not become available until later in the semesters (no matter how concrete the plans for data collection may be).
TipData Example I
Hourly [1: time] counts of bicycles [2: attribute] at one location (space: not substantial) do not fulfill the requirements. You may add data from several locations [3: space] or weather data like daily sunshine duration [4: attribute] and amount of rain [5: attribute] for the locations and days analysed to fulfill the data dimension requirement.

TipData Example II
20-year averages (no substantial time data dimension) of maximum temperatures [1: attribute] for many different locations [2: space] in the USA give you only two data dimensions. Using 20-year averages of daily [1: time] maximum [2: attribute] and minimum [3: attribute] temperatures for several different locations [4: space] fulfills the minimal data dimension requirement.

Part B.1 - Visual Data Exploration
1-2 A4 pages of 2 or 3 exploration graphics (static visualizations in the pdf document, screen-shot and working URL for dynamic visualizations [note: dynamic visualizations are NOT a requirement]), show at least two different levels of aggregation of one of the data dimensions (e.g., daily data in one graphic and aggregated weekly data in another graphic) and use at least three of your four substantial data dimensions 1 A4 page of structured description (maximum 500 words, word count does not include detailed references to sources of the used raw data and any other information used for the task) how your visual exploration of which data lead to the insight(s) communicated in B.2, how you verified your insights, and how you ensure that B.2 clearly communicates the insight(s) (design aspects).

Part B.2 - Visual Insight(s) Communication
Single communication visualization / Information Graphic (maximum 1 A4 page, static) that communicates and explains the insight(s)

Part B.3 - Raw Data Used
A single file or package of files (e.g. zip) of all used — but only the used (not all downloaded) — raw data for the task using standard file formats (.csv, .json,…). If for a reason you are not able to submit the raw data or only parts of the used data, note it in the questionnaire in SW04.
